# 주식투자 학습 프로젝트

Streamlit의 기본 입력 기능과 표, 차트를 연습하기 위한 주식투자 주제의 학습용 프로젝트입니다.

이 프로젝트에서 사용하는 가격, 거래량, 투자 성향과 주문 정보는 모두 예제입니다. 실제 투자 자문, 금융상품 추천 또는 주식 주문 기능을 제공하지 않습니다.

## 파일 구성

```text
app_pages/port
├── charttable.py
├── survey.py
├── pizza.py
└── port.md
```

## `charttable.py`

학습용 주가와 거래량 데이터를 표와 차트로 확인합니다.

- 종목별 모의 주가 표
- 확인할 종목 선택
- 선택한 종목의 가격 변화 선 차트
- 종목별 모의 거래량 표
- 종목 이름을 가로로 표시하는 막대 차트

## `survey.py`

간단한 주식투자 성향 설문을 작성하고 결과를 확인합니다.

- 투자 경험
- 투자 예정 기간
- 관심 업종
- 감당 가능한 손실 범위
- 추가 의견
- 손실 허용 범위에 따른 안정형, 중립형, 공격형 구분

## `pizza.py`

파일명은 기존 과제 구조를 유지하고, 화면 내용은 모의 주식 주문서로 구성했습니다.

- 삼성전자, SK하이닉스, NAVER 예제 버튼
- 종목 선택 시 모의 가격과 수량 자동 입력
- 종목명, 주문 가격, 주문 수량 수정
- 모의 주문 결과 확인
- 입력 내용 초기화

## 로컬 테스트

프로젝트 가상환경을 활성화한 뒤 로컬 테스트 앱을 실행합니다.

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run .\test_app.py
```

테스트 앱의 왼쪽 메뉴에서 메인 화면과 세 기능 페이지로 이동할 수 있습니다.

## 주의사항

- 실제 주가를 조회하지 않습니다.
- 증권사 또는 외부 주식 API와 연결하지 않습니다.
- 실제 매수나 매도 주문을 실행하지 않습니다.
- 화면에 표시되는 숫자는 Streamlit 학습을 위한 모의 데이터입니다.
